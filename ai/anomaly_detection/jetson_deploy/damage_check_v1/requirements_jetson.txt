# Jetson Orin Nano, JetPack 6.2.1(CUDA 12.6, TensorRT 10.3) 확정 — 학습용
# requirements.txt와 다르다. anomalib / lightning / timm / scikit-image 등 학습
# 프레임워크는 여기 없다. (임베디드 파트 확인: JetPack 6.2.1, 2026-07-30)
#
# ⚠️⚠️ 절대로 `pip install -r requirements_jetson.txt`를 그대로 실행하지 말 것.
# torch·onnxruntime-gpu는 PyPI에 Jetson(aarch64) 공식 빌드가 없다 — 그냥 설치하면
# "is not a supported wheel on this platform" 에러가 나거나, 최악의 경우 CPU 전용
# 범용 ARM 빌드가 깔려 TensorRT/CUDA 가속이 아예 안 붙은 채로 조용히 "설치는 된다".
# 아래 명령을 순서대로 실행할 것(2026-07-30, jp6/cu126 인덱스에서 버전까지 확정 확인).
#
# ── 1. torch · torchvision ────────────────────────────────────────────────
#   python -m pip install torch==2.11.0 torchvision==0.26.0 \
#     --index-url=https://pypi.jetson-ai-lab.io/jp6/cu126
#
# ── 2. onnxruntime-gpu ────────────────────────────────────────────────────
#   python -m pip install onnxruntime-gpu==1.24.0 \
#     --index-url=https://pypi.jetson-ai-lab.io/jp6/cu126
#   ⚠️ `pypi.jetson-ai-lab.dev`(.dev 도메인)가 아니라 **`.io` 도메인**을 쓸 것 —
#   .dev는 2026-07-30 확인 시점에 DNS 자체가 안 잡혔다(간헐적으로 다운되는 것으로
#   보임). .io의 jp6/cu126 인덱스에 onnxruntime-gpu 1.24.0이 정상 확인됨.
#
# ── 3. numpy 버전 확인 ────────────────────────────────────────────────────
#   위 onnxruntime-gpu 설치 후 반드시 확인:
#     python -c "import onnxruntime, numpy; print(numpy.__version__)"
#   에러 없이 돌면 통과. 일부 Jetson용 onnxruntime-gpu 휠이 numpy 1.x를 요구해
#   충돌할 수 있으니, 에러가 나면 그 요구사항에 맞춰 numpy를 재설치할 것.
#
# ── 4. 나머지 ─────────────────────────────────────────────────────────────
#   pip install opencv-python numpy ultralytics
#
# ⚠️ 학습 측(x86 PC, torch 2.6.0+cu124)과 Jetson 측(torch 2.11.0+cu126) CUDA 버전이
# 서로 다른 건 정상이며 맞출 필요 없다 — PatchCore는 ONNX로 배포되고(CUDA 버전
# 비종속), YOLO(`yolov8n.pt`)도 Jetson 자체 torch로 로드되므로 학습 측과 독립적이다.
# 오직 "Jetson 안에서 torch·onnxruntime·JetPack·TensorRT끼리" 버전이 맞으면 된다.

onnxruntime          # 위 2번 참고 — 위 확정 명령으로 onnxruntime-gpu 1.24.0으로 교체할 것
opencv-python
numpy
ultralytics          # ①DETECT(YOLOv8n)용 — torch를 딸려온다, 위 1번 참고
