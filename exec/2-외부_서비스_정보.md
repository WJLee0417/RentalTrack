### Toss Payments (미정산 결제 · `PAYMENT-001`)

미정산 금액이 있으면 새 대여가 제한되며, 사용자 앱에서 결제를 완료해야 다시 대여할 수 있습니다.

**가입 및 키 발급**

- https://developers.tosspayments.com 개발자센터 회원가입
- 가입 즉시 **테스트 상점**이 생성되고 테스트 키가 발급됩니다 (사업자 등록 불필요, 실제 청구 없음)
- 내 개발정보 > **API 키**에서 두 가지를 확인합니다

| 키 | 접두사 | 쓰는 곳 | 성격 |
|---|---|---|---|
| 클라이언트 키 | `test_ck_...` | 사용자 앱 결제창 호출 | 클라이언트 노출 전제. 공개돼도 승인 불가 |
| 시크릿 키 | `test_sk_...` | Spring 결제 승인 API | **절대 비공개.** 유출 시 임의 승인 가능 |

**주입 경로**

| 환경변수 | 대상 | 경로 |
|---|---|---|
| `TOSS_CLIENT_KEY` | 사용자 앱 | Expo 환경변수 (`EXPO_PUBLIC_` 접두사 필요 — 번들에 포함되는 값) |
| `TOSS_SECRET_KEY` | Spring | 로컬 `backend/.env` / 배포 GitLab CI/CD 변수(Masked+Protected) → `docker-compose.yml` |

> `GMS_KEY` · `KMA_API_KEY` 와 동일한 방식입니다. 시크릿 키는 `.env.example` 에 `changeme` 로만 두고
> 실제 값은 저장소에 올리지 않습니다.

**승인 API**

- `POST https://api.tosspayments.com/v1/payments/confirm`
- 인증: HTTP Basic — `Base64(시크릿키 + ":")` (비밀번호 없이 콜론까지 포함)
- 본문: `paymentKey` · `orderId` · `amount`
- **금액 검증은 서버가 합니다.** 클라이언트가 보낸 금액을 그대로 승인하면 안 되고,
  `settlement` 의 미정산 잔액과 대조한 뒤 승인해야 합니다

**DB 계약 — 이미 스키마에 반영돼 있습니다**

`payment_attempt` 테이블에 관련 컬럼이 준비돼 있습니다.

| 컬럼 | 용도 |
|---|---|
| `creation_request_id` | **멱등키.** 같은 요청 재전송 시 중복 결제 방지 |
| `toss_order_id` · `toss_payment_key` | Toss 측 식별자 |
| `toss_status` | Toss 원본 상태 문자열 |
| `provider` | PG 구분자 |
| `status` | 빌리산 내부 상태 |
| `amount` · `requested_at` · `approved_at` · `completed_at` | 금액·시각 |

내부 상태 ↔ Toss 상태 매핑은 [V11 마이그레이션](../backend/src/main/resources/db/migration/V11__map_internal_and_toss_payment_statuses.sql)이
**권위 있는 정의**이며 CHECK 제약으로 강제됩니다. 구현 시 이 표를 따라야 합니다.

| 내부 상태 | Toss 상태 |
|---|---|
| `REQUESTED` | Toss 객체/상태 없음 |
| `PROCESSING` | `READY` \| `IN_PROGRESS` \| `WAITING_FOR_DEPOSIT` |
| `SUCCEEDED` | `DONE` |
| `FAILED` | 로컬 실패(NULL) \| `ABORTED` \| `EXPIRED` |
| `CANCELLED` | 로컬 취소(NULL) \| `CANCELED` |
| `RECONCILIATION_REQUIRED` | `PARTIAL_CANCELED`, 신규/역행 상태 |

> ⚠ `PARTIAL_CANCELED` 를 `CANCELLED` 로 매핑하면 안 됩니다. `payment_attempt` 에 부분취소·환불 금액
> 필드가 없어서, 누적 `settlement` 정산이 끝날 때까지 `RECONCILIATION_REQUIRED` 로 보존합니다.
> `DONE → WAITING_FOR_DEPOSIT` 같은 드문 역행도 같은 상태로 흡수합니다.
>
> 웹훅 멱등성·전이 적법성·이전 상태 비교·`settlement.paid_amount` 갱신·순서 뒤바뀐 이벤트 처리는
> **행 잠금 또는 `updated_at` CAS 로 보호되는 단일 Spring 트랜잭션**이어야 합니다 (V11 주석 명시).

**웹훅**

- 개발자센터 > 웹훅에서 수신 URL 등록
- 백엔드가 평문 HTTP(8080)이므로 Toss가 요구하는 HTTPS 수신에 제약이 있는지 확인 필요
  (관리자 Web과 달리 Vercel rewrite 프록시를 쓸 수 없는 서버 대 서버 호출입니다)

> **현재 상태(2026-08-08)** — DB 스키마와 상태 매핑은 완료, **서버 배선·키 발급·앱 결제창은 구현 중**입니다.
> 시연 전 위 두 환경변수가 실제로 주입됐는지 확인하세요.

## 계정이 필요한 서비스

### Vercel (관리자 Web 배포)

- https://vercel.com 회원가입 후 프로젝트 연결. Hobby 플랜 무료
- 배포 URL `https://web-sigma-two-20.vercel.app`
- **GitLab CI 파이프라인 경로가 아닙니다.** `.gitlab-ci.yml` 은 `backend/ci.yml` 만 include하고
  `frontend/ci.yml` 은 주석 처리 상태입니다
- **`VITE_API_BASE_URL` 은 상대 경로 `/api/v1/admin` 을 유지합니다.**
  - 배포본은 HTTPS(Vercel), 백엔드는 평문 HTTP(8080)입니다. 절대 URL을 넣으면 브라우저가
    혼합 콘텐츠로 차단하며, 사용자가 무시할 UI조차 없습니다
  - `frontend/web/vercel.json` 의 rewrite가 **서버 대 서버로 중계**합니다
    ```json
    { "source": "/api/(.*)", "destination": "http://i15a201.p.ssafy.io:8080/api/$1" }
    ```
- **CORS는 이 프록시로 해결되지 않습니다.** 브라우저가 POST·PATCH에 `Origin` 을 붙이고
  Vercel이 그대로 전달하므로, Spring `CorsFilter` 허용 목록에 배포 도메인이 없으면 403입니다
  - 현재 `backend/docker-compose.yml` 에는 `ADMIN_CORS_ALLOWED_ORIGINS` 가 없고,
    `application.yaml` 의 기본값에 `https://web-sigma-two-20.vercel.app` 이 포함되어 동작 중입니다
  - **배포 도메인이 바뀌면 rewrite 목적지와 CORS 허용 목록을 둘 다 고쳐야 합니다**
- Vercel 미리보기 URL은 배포마다 도메인이 달라 허용 목록에 넣을 수 없고 Deployment Protection이
  `/api/*` 까지 막습니다. **검증은 고정 주소로 하세요**
- 그 외 환경변수: `VITE_APP_NAME`, `VITE_MOCK_AUTH`, `VITE_USE_MOCK_DATA`, `VITE_AUTH_BYPASS`,
  `VITE_DEMO_ADMIN_ID`, `VITE_DEMO_ADMIN_PASSWORD` (저장소에 값을 두지 않고 환경변수로 주입)

### AWS EC2 (서버 호스팅)

- SSAFY 제공 인스턴스, SSH 키 페어로 접속. 주소 `i15a201.p.ssafy.io`
- `backend/docker-compose.yml` 로 app(8080) · MySQL · Mosquitto 구동
- **MQTT 포트 — 두 개를 구분해야 합니다**
  - `docker-compose.yml` 의 mosquitto는 **호스트 1883에 매핑**되어 있습니다 (`"1883:1883"`).
    컨테이너 전용이 아닙니다
  - 다만 Pi가 실제로 붙는 경로는 **`i15a201.p.ssafy.io:80` → iptables 리다이렉트 → 18883**
    입니다 (443은 백엔드 몫). `iot/pi/billisan/config.py` 의 `BROKER_PORT = 80`
  - `backend/mosquitto.conf` 는 `listener 1883` · **`allow_anonymous true`** 입니다.
    인증 없이 접속을 허용하므로, 호스트 1883 이 외부에 열려 있는지는 EC2 보안그룹으로 통제해야 합니다

### GitLab (lab.ssafy.com · 형상관리 · CI/CD)

## 사용하지 않는 외부 서비스

- **소셜 인증(OAuth)** — `login_id` + `password` 자체 인증 사용
- **포톤 클라우드** — 실시간 멀티플레이 네트워킹 불필요
- **외부 코드 컴파일 서비스** — GitLab CI에서 직접 빌드
- **npm · PyPI · Maven Central** — 공개 패키지 다운로드만 하므로 계정 불필요
- **Gradle 배포 서버** — `services.gradle.org/distributions/gradle-9.5.1-bin.zip`.
  Gradle Wrapper가 최초 빌드 시 자동 다운로드. 계정 불필요
